# PAT Basic Level Practice by C++

本仓库收录 PAT Basic Level Practice 题库的 C++17 题解，共 125 道题目，题号范围为 1001～1125。

每道题均提供独立的源码和 Markdown 题解，适合用于 PAT 基础题练习、算法复习和 C++ 语法训练。

## 项目特点

- 使用 C++17 实现，每道题对应一个独立的 `main.cpp` 文件。
- 题解文档包含题目描述、输入输出格式、样例、解题思路、代码流程说明、完整代码和流程图。
- 源码包含算法原理、关键步骤和必要的边界处理注释。
- Markdown 中的“代码实现”直接嵌入对应源码，便于阅读和复制提交。
- Mermaid 流程图采用小规模 `flowchart TD`，降低渲染失败和内存超限风险。

## 目录结构

```text
PAT_Basic_Level_Practice_by_CPP/
├── README.md
├── 1001-题目名称/
│   ├── main.cpp
│   └── 1001-题目名称.md
├── 1002-题目名称/
│   ├── main.cpp
│   └── 1002-题目名称.md
└── ...
```

目录名称由“题号-题目名称”组成。每个题目目录中的 Markdown 文件与 `main.cpp` 一一对应，例如：

- [1034 有理数四则运算](./1034-有理数四则运算/)
- [1050 螺旋矩阵](./1050-螺旋矩阵/)
- [1110 区块反转](./1110-区块反转/)

## 编译与运行

每道题独立编译，不需要额外的第三方库。以 1034 题为例：

```bash
g++ -std=c++17 -O2 -pipe "1034-有理数四则运算/main.cpp" -o solution
./solution < input.txt
```

也可以直接在 PAT 提交对应目录中的 `main.cpp` 内容。源码使用了 `bits/stdc++.h`，建议使用支持该头文件的 GCC 或 Clang 环境。

## 题解文档说明

每份 Markdown 文档按照统一模板组织，主要章节如下：

1. 题目描述
2. 输入格式与输出格式
3. 输入样例与输出样例
4. 解题思路
5. 代码流程说明
6. 代码实现
7. 代码流程图与解题流程图
8. 常见易错点

流程图使用 Mermaid 语法。查看流程图时，请使用支持 Mermaid 的 Markdown 编辑器或文档平台。
