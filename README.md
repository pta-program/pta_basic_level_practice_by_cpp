# PAT Basic Level Practice by C++

PAT Basic Level（乙级）题目练习仓库，使用 C++ 记录题解与可提交代码。

## 仓库内容

- 覆盖题号 **1001–1125**，当前共 **125** 道题目。
- 每道题目独立存放在一个目录中，目录格式为 `题号-题目名称`。
- 题目目录通常包含：
  - `题号-题目名称.md`：题目描述、输入输出格式、解题思路与流程说明；
  - `main.cpp`：C++ 参考实现；
  - `image/`：部分题目说明所引用的图片资源。

## 目录示例

```text
1001-害死人不偿命的(3n+1)猜想/
├── 1001-害死人不偿命的(3n+1)猜想.md
└── main.cpp
```

## 如何使用

进入任意题目目录后编译运行：

```bash
cd "1001-害死人不偿命的(3n+1)猜想"
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o solution
./solution
```

也可以直接在 PTA 题目页面提交对应的 `main.cpp`。不同题目的输入输出要求不同，请以该题目目录中的 Markdown 说明为准。
