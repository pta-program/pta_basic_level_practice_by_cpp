## 📖 项目简介

本仓库整理 PAT Basic Level Practice 题库的 C++17 题解，覆盖 1001～1125 共 125 道题目，适合：

- 学习 C++ 基础语法、STL 和常见算法；
- 通过 PAT 题目练习模拟、字符串、排序、数学、链表和图论等内容；
- 对照题目说明、实现原理和流程图理解代码执行过程；
- 直接复制对应的 `main.cpp` 到 PTA 编译提交。

每道题均包含：

- 题目描述、输入格式、输出格式和输入输出样例；
- 解题思路与代码流程说明；
- 带算法原理和关键步骤注释的完整 C++17 实现；
- 代码流程图、解题流程图和常见易错点。

## 🗂️ 目录结构

每道题使用独立目录，目录名格式为「题号-题目名称」：

```text
PAT_Basic_Level_Practice_by_CPP/
├── README.md
├── 1001-题目名称/
│   ├── 1001-题目名称.md
│   └── main.cpp
├── 1002-题目名称/
│   ├── 1002-题目名称.md
│   └── main.cpp
└── ...
```

Markdown 文档中的“代码实现”与同目录 `main.cpp` 保持同步，可从题目索引进入对应目录查看。

## 🚀 快速开始

### 在线查看

直接打开题目目录中的 Markdown 文件，阅读题目、思路、流程图和完整代码。

### 本地编译运行

每道题独立编译，不需要额外的第三方库。以 1034 题为例：

```bash
g++ -std=c++17 -O2 -pipe "1034-有理数四则运算/main.cpp" -o solution
./solution < input.txt
```

源码使用 `bits/stdc++.h`，建议使用 GCC 或配置了 GNU C++ 标准库的 Clang 环境。

## 📝 题解文档结构

每份题解按照统一模板组织：

1. 题目描述
2. 输入格式与输出格式
3. 输入样例与输出样例
4. 解题思路
5. 代码流程说明
6. 代码实现
7. 代码流程图与解题流程图
8. 常见易错点

流程图使用 Mermaid `flowchart TD` 语法。图形保持小规模，避免 Markdown 平台渲染时出现复杂布局或内存占用过高的问题。
